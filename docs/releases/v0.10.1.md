# v0.10.1

只做一件事：**给程序和安装包加上图标**。功能与 v0.10.0 完全一致。

### 修复

- **`wslc-panel.exe` 现在有图标了**。之前它在桌面/开始菜单/任务栏/Alt+Tab 上
  都是一张**白纸** —— 那个 exe 是没有任何资源段的裸 PE。
- **安装包也有图标了**（下载页和安装向导里不再是一张白纸），并且
  「卸载」快捷方式用的是系统卸载图标，一眼能看出它不是主程序。
- 「属性 → 详细信息」现在有程序名、版本、许可证。

### 图标是什么

深色面板窗口 + 左侧蓝色侧边栏 + 右侧三行列表（首行高亮）。7 档尺寸
（16/24/32/48/64/128/256），小到任务栏 16px 也还认得出"左边一条、右边几行"。

它是**程序化生成**的（`assets/make-icon.py`），不是找来的图 —— 这样许可证干净，
以后改配色也只改那个脚本。

### 顺带加固的一处

发布流水线现在会**读 PE 资源表**确认图标真的进了 exe，没有就报错、不发包。
加这一步是因为 v0.10.0 的教训：`cargo check` 只做类型检查、不链接，
而资源编译失败在 build 脚本里是**静默降级**的 —— 两个叠加就变成
"图标没了但 CI 和 release 全绿"。

### 取哪个文件

三种内容一样，**只需要一个**：
`setup-x64.exe`（安装包）/ `wslc-panel.exe`（绿色单文件）/ `.zip`（含 README 与 docs）。

**完整变更**：https://github.com/SilkKirk/wslc-panel/compare/v0.10.0...v0.10.1
