# v0.17.1 —— 三个真 bug + 界面统一

这一版**没有新功能**。它是一次"把欠的账还掉"的发布：三个会导致用户踩坑的
缺陷、一次全应用的界面规范化、以及一批工程债。

---

## 一、三个真 bug（建议都看一下）

### ① 原生连接下，六个动作会打出"指错方向"的错 ✅ 最该修的一条

v0.16 加了「连接串 → 原生连接」之后，页面的**读**换了（不再经过容器），
但六条**写**动作没换：**备份 / 恢复 / 导入备份 / 建库建用户 / 删库 / 删用户**。

它们仍然是 `wslc exec <容器> <客户端>`，而原生探测把客户端名写成了一个
哨兵值 `native`。于是：

> 粘一条 `mysql://root:pw@10.0.0.5:3306/shop` → 页面能连、SQL 跑得好好的
> → 点「备份」→ 拿到 `exec: native: not found`

**问题不是"报错"，是报了一个指错方向的错** —— 看上去像容器坏了，
而真实原因是这条路压根没接原生驱动。

现在原生连接下那六个按钮**不画**，页面上给一行说明（29 字）：

> 原生连接不支持备份、导入、建库等操作，清空连接串即可恢复。

SQL 控制台不受影响。想用备份就把连接串清空，回到"在容器里执行"。

### ② TLS 握手失败一直被说成"数据库错误" ✅ 新测试抓到的

`wslc-db` 里分类 PostgreSQL 连接错误的那段，判据写的是 `contains("tls")`（全小写），
而驱动自己的措辞是 `error performing TLS handshake`（大写 `TLS`）。
**匹配不上**，于是 TLS 失败落进"其它"，界面上说"数据库错误"。

同一台服务器、同一个错误：改之前你看到"数据库错误"，改之后看到"TLS 握手失败"。
一句"该去查证书还是查口令"的区别。

（这个 bug 是补测试时暴露的 —— 原来那条测试断言的是 `"28P01".starts_with("28")`，
测的是标准库，不是我们的代码。）

### ③ 连接串的口令会进日志；切容器时不清输入框

- `DbState` 是 `#[derive(Debug)]`，而 `dsn` 字段是裸 `String`。这个仓库在密码上
  一向守得很死（`MysqlCreds` / `DbCredential` 都手写了脱敏 `Debug`），
  而 v0.16 新加的这个字段**破坏了那条不变式** —— 任何一次 `{:?}` 都会把口令
  打进日志文件（而日志是用户出问题时会贴到 issue 里的东西）。
  现在改成 newtype，只遮口令段，主机 / 库名 / 用户名保留（那是排障要看的）。

- 切容器时清了密码，却**没清连接串** —— 而它比密码更危险（既有口令又有主机）。
  现在一起清。

## 二、界面：统一规范

这一版把"同一类控件应该长得一样"落到了实处。**每一处都变了样**，
装着新版第一眼就能感觉到。

### 弹窗宽度：6 种 → 3 种

实测 19 个弹窗的宽度有 **6 种**取值：

```
560 / 620 / 680 / 700 / 760 / 780 / 820
```

后果用户能看见：点「创建容器」(780) 再点「执行命令」(760)，**卡片边缘会挪 20px**。
现在收成三档（560 / 700 / 800），**17 处**统一。

⚠️ 有一处**刻意保留**不同：删除确认框用红色边框（`danger_edge`）——
那是"不可撤销"的视觉契约，不是散落。只统一了宽度。

### 组件换成官方的

| 换成 | 原来手写的 |
|---|---|
| `Tag`（带边框 / hover / 圆角 token） | 三行 `div` 拼的徽标 |
| `TabBar` + `Tab`（胶囊态 + 键盘导航） | 拿 `Button` 拼的选项卡 |
| `Alert`（底色 / 边框 / 图标由组件画） | 手写的错误横幅 |
| `Spinner`（真的转圈） | 只换文字的"正在读取…" |
| `Icon`（Lucide `ChevronDown` + 旋转） | `▾` / `▸` 这两个字体字符 |
| `Empty`（虚线框 + 撑满） | 整页空状态 |
| `DescriptionList`（标签列对齐） | 「关于」页四行键值对 |

配色**没有**变成"第二套"：组件库的强调色 / 危险色 / 边框色本来就由
`theme::tune_component_theme` 换成我们自己的，所以观感一致。

### 提示文案：删掉"解释"，留下"动作"

最长的一条是我自己上一版加的（80+ 字三行），压到 29 字。
判据是**这条提示要用户做什么** —— 可操作的信息留下，背景知识该在真卡住时再出现。

同类清理了：反代规则说明、`.wslconfig` 三段并两段、三处把**内部状态**当文案的
空状态（"SQL 编辑器还没建好" → "请从容器页的数据库按钮重新进入"）。

## 三、工程债

- **`lint`（rustfmt + clippy）从"只报告"改成阻塞。** 原先 37 条 clippy 警告从
  v0.10 挂到 v0.17，没有任何后果，于是从来没人清。现在清到 **0 条**，
  改成阻塞 —— 以后任何一次提交引入格式问题或新警告都会立刻红。
- `fmt.yml` 不再用 `git add -A`（它会把安装脚本的换行形态一起提交进
  `style: cargo fmt` 里，实测过）。
- 修掉 `views.rs` 里**370 行被插入空行**的代码（v0.12 起的格式事故，
  `cargo check` 不报、rustfmt 也不管 —— 没有任何自动化关卡能发现它）。
- 删掉 7 个为「已经不存在的实现」抓的夹具。
- 清掉 3 条**永不执行**的测试（`wslc-panel` 不在 CI 的测试目标里，写在那儿的
  断言只编译、不执行），搬到能跑的地方。
- 文档对齐：README 架构图（三个 crate → 四个）、GPUI 版本（0.7.1 → 0.8.0）、
  `--pull` 自相矛盾的一句、4 处过时 MSRV 注释、AGENTS 的发版清单
  （锁文件成员是三→四、六行→七行）。

## ⚠️ 装上后请重点看这几处

这一版的界面改动**都只证明了"能编译"**（CI 不跑渲染）。请扫一眼：

1. **徽标**现在有边框和 hover 了（容器状态、系统库标记、"默认"标记……）；
2. **选项卡**（数据库页 / 设置页）变成胶囊态，不再是"选中的按钮变蓝"；
3. **折叠箭头**是图标了，展开时旋转 180°；
4. **整页空状态**（没有任何容器 / 还没有备份）有虚线框；
5. **弹窗宽度**变了（760/780 → 800，520 → 560）；
6. **「关于」页**四条键值对的标签列对齐了。

如果哪里不对，回退路径很干净：`git revert` 对应提交即可，这一版没有数据格式变更。
