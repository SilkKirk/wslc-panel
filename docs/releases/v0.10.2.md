# v0.10.2

只改图标。功能和 v0.10.1 完全一致。

### 变化

图标换成**插画里角色的头部**（用户提供的立绘），做成 Windows 11 风格的圆角方块。

之前几版的问题：

- v0.10.0 的 exe **没有任何图标资源**，桌面上一张白纸；
- v0.10.1 换了程序化绘制的图形，但在**暗色任务栏**上糊成一片。

现在是"只截头部 + 22% 圆角 + 极淡内高光"，和桌面上的 March7th Launcher 同一路做法。

### 已知限制

**16px（标题栏）会糊成一团浅色小点** —— 这是插画类图标的固有代价。
48px（桌面大图标）和 32px（任务栏）清晰，32px 仍能认出是个人物。

### 取哪个文件

三种内容一样，**只需要一个**：
`setup-x64.exe`（安装包）/ `wslc-panel.exe`（绿色单文件）/ `.zip`（含 README 与 docs）。

**完整变更**：https://github.com/SilkKirk/wslc-panel/compare/v0.10.1...v0.10.2
