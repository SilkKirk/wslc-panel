# v0.10.0

本版加了两个东西：**安装包**，以及**「有新版本」提示**。

更新提示只负责告诉你「有新版了」，**不会**自己下载或替换程序 ——
下载按你习惯的方式走（发布页 / 加速站都行）。

### 新增

- **安装包** `wslc-panel-0.10.0-setup-x64.exe`
  - 装到 `%LOCALAPPDATA%\Programs\wslc-panel`，**不需要管理员权限**，不弹 UAC；
  - 带开始菜单快捷方式、可选桌面图标、「应用和功能」里的卸载项；
  - 卸载时会问一句**要不要连数据一起删**（默认保留）。数据（偏好 / 日志 /
    部署记录 / 数据库账号）在 `%LOCALAPPDATA%\wslc-panel`，装与不装安装包都用这一份。
  - 用它升级时，如果面板正在运行，安装器会先把它关掉 —— 但**不会**连带停掉
    你用它「启动」着的 WSL 发行版。

- **「检查更新」**（应用设置 → 关于）
  - 启动 8 秒后自动查一次，**24 小时最多一次**；可以在卡里整个关掉；
  - 发现新版本：弹一条提示，卡片里常驻显示版本号、发布日期和发布说明开头，
    配一个**「打开发布页」**按钮；
  - 支持**「跳过这个版本」**，跳过的版本不再提示；
  - 查失败**不会**在界面上报错（只写日志）—— 这是个本地工具，不该因为一次
    网络失败每天弹一句"检查更新失败"。手动点「检查更新」时才把错误告诉你。

### 说明

- 除了上面那个 `GET /releases/latest`，本版**没有**新增任何外发请求。
  请求不带身份信息，只有一句 `User-Agent: wslc-panel/0.10.0`。
- 三种取法内容完全一样，**只需要下载一个**：
  `setup-x64.exe`（安装包）/ `wslc-panel.exe`（绿色单文件）/ `.zip`（含 README 与 docs）。
- 安装版和绿色版可以共存，但它们**共用**同一份数据目录。

### 验证

- CI 的纯逻辑测试 **531 + 201 + 18 条全部通过**（新增约 30 条：版本比较、
  GitHub 响应解析、「跳过版本」判据、24 小时节流、prefs 升级）；GPUI 编译检查通过。
- ⚠️ 安装包与「关于」页新卡片的**界面表现需要实机确认** —— CI 只能证明编译过、
  逻辑对，证明不了渲染成什么样。
