# v0.12.3

SQL 页按专业客户端的做法重做了一遍外壳：**顶栏砍到三样东西**，左侧表结构树
换成组件库的树控件，侧边栏和树都能折叠。

> 如果你装的是 v0.12.0，这一版会一次带上三次改动（12.1 树的样式、12.2 折叠、
> 12.3 顶栏精简）。

### 顶栏：从"四五个按钮 + 两行标题"到"三个东西"

```
[☰]  [← 数据库]  [djxm]
────────────────────────────────────────────
表结构 · 110 张表                  ⟳   «
[搜索框]
```

- **这一页不再显示应用级页头**。原来顶部同时有「SQL 控制台」大标题、
  「最后刷新：21 秒前 · 自动刷新 30 秒」、右上角「刷新」按钮，
  再加 SQL 页自己的四个按钮 —— 而那个「刷新」刷的是容器列表和数据库列表，
  跟这一页要看的数据没关系。
- 「刷新表结构」→ 树头右上角的 **`⟳`**。
- 「隐藏表结构」→ 树头右上角的 **`«`**。树收起后留一条 32px 窄条（上面是 `»`），
  随时能开回来。

### 表结构树换成了组件库的 `Tree`

之前是自己逐行画的，问题很具体：每一行都带整行宽度的底色和内边距，而且
**文字是居中的** —— 于是 `    sys_user` 和 `sys_user` 看起来一样，缩进读不出来，
110 行像 110 个色块。

现在用 `gpui-kit` 自带的 `Tree`：

- 缩进按**层级**算（`px(14) * depth`），长短表名会对齐；
- 悬停 / 选中由组件管，平时无底色；
- 虚拟滚动，110 张表只画可见行；
- 点库名展开 / 收起是组件自带的行为。

搜关键字时把结果**拍平**成一层的「库.表」 —— 否则你搜到的那张表还藏在一个
收起的库节点里，得再点一下才看得见。

### 左侧菜单栏也能折叠

换成组件库的 `Sidebar`，点标题左边的 **`☰`** 收起。收起时它完全退出布局，
主区域拿到全部宽度。分组标题、悬停、选中态都由组件负责。

### 其他精简

提示文案从「SHOW / SELECT / DDL 都能跑；多条语句逐条执行（每条约 70ms 起步）」
减成「多条语句逐条执行（每条约 70ms）」—— 前半句是废话，留下的是你
看不出来的那条行为（会以为是一次性提交）。

### 需要你知道的

- 图标用的是 `⟳` `«` `»` `☰` 字符，不是图标字体。这些是 Unicode 标准字符，
  任何字体都有；换成图标集要逐个确认变体名存在，改错会编译失败。
- **这一版的界面改动全部只到"编译通过"，没有实机验证过**。所以你要的这版
  正好就是来给我反馈的。
